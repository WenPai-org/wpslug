# WPSlug 1.3 changelog 草稿

人过 Gate 3 并改 Version / Stable tag 之前，不要把本节写进 `readme.txt`。现在 Stable tag 仍是 1.2.6。

= 1.3.0 =
* Added: wenpai-admin-ui 0.2.3 settings shell — 概览 / 设置（简单|高级）/ 工具；帮助是页头链，不是第四个 Tab。
* Added: `wp slug` CLI — status, preview, convert [--dry-run] [--yes], doctor. Secrets print as set or empty.
* Changed: 启用插件关掉时立刻隐藏转换模式、三项开关和设置页预览（`.wpslug-when-on`），不 disable 输入。
* Changed: 预览原文长显，别名有结果才出现；成功整框绿，失败整框红。
* Changed: 简单页转换模式 `.field` 一列；无心思默认三卡为本地拼音 / 多语言翻译 / 外语音译。
* Changed: 后台字重 400，层级靠留白和间隔。
* Changed: 窄屏页头帮助和反馈只显示图标；782px 勾选裁切和页签铺满。
* Changed: 帮助页按智储结构：快速开始 + details 手风琴。
